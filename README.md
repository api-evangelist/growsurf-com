GrowSurf provides referral program software that turns patients, members, and customers into a low‑cost growth channel. It serves telehealth, fintech, insurance, and subscription apps, delivering up to 312% ROI and 15% of ARR from referrals. The platform offers 60+ integrations, a REST API, JavaScript library, and webhooks to automate referral tracking and rewards.

**Areas:** Referral · Marketing · SaaS · Healthcare · Fintech · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for GrowSurf: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
